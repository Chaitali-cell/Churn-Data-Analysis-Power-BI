# 📊 Churn Data Analysis Dashboard – Power BI

## 📌 Project Overview

This project is an interactive Customer Churn Analysis Dashboard created using Microsoft Power BI.
The dashboard analyzes customer churn based on contract type, gender, payment method, churn category, state and churn reasons.

## 📊 Key KPIs

- Total Customers: 6,687
- Churned Customers: 1,796
- Churn Rate: 26.86%
- Total Charges: 7M
- Monthly Charges: 208K
- Average Monthly Charge: 31.03
- Customer Count: 6,123

## 🔍 Dashboard Features

- Churn analysis by Contract Type
- Average Total Charges by Payment Method
- Gender Distribution
- Churn by State
- Churn by Reason
- Customer Summary Table
- Interactive filters for:
  - Churn Label
  - Contract Type
  - Gender
  - Payment Method
  - Churn Category

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization
- Business Intelligence

## 🎯 Objective

The objective of this project is to analyze customer churn patterns and identify important factors associated with customer retention and churn.

## 📈 Key Insights

- The overall churn rate is 26.86%.
- Month-to-month customers show higher churn compared with longer-term contracts.
- Churn varies across different payment methods.
- Churn reasons and categories provide insights into customer retention problems.
- Gender-wise customer distribution is also analyzed.
