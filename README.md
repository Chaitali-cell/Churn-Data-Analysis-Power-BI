# 📊 Churn Analysis Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **Churn Analysis Dashboard** created using Microsoft Power BI.
The dashboard analyzes customer churn patterns based on contract type, payment method, gender, state, churn category and churn reasons.
The project helps identify important factors affecting customer retention and churn.

---

## 🎯 Project Objective

The main objective of this project is to analyze customer churn data and understand:

- Customer churn rate
- Churned and retained customers
- Contract-wise churn
- Payment method analysis
- Gender-wise customer distribution
- State-wise churn
- Churn categories
- Reasons for customer churn
- Customer and revenue-related metrics
